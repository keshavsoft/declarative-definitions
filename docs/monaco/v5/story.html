Design Philosophy

What makes V5 different?

1. No Header / Topbar Clutter

Every vertical pixel is preserved. The distracting 64px navigation bar and story banners are completely eliminated.

2. Immediate 3-Tier Hierarchy

Instantly drill down: Control Type → Variation → Contract Part (or Show All) with zero latency.

3. Modular Component Isolation

Driven by dom-primitive-bindings v8 with strictly decoupled components/left, components/right, and workspace folders.

4. Production Module Loader

Direct dynamic ESM import of the live distribution module with fallback resilience, ensuring it always loads the latest blueprints.

How to use: Start with index.html in this folder whenever you need to inspect or copy definition JSON keys into your UI pipeline.
