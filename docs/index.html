A small story about a big idea
declarative-definitions · V1

A control is more than a name.
It is a definition.

A table. A select. A form. We know what these controls are. But when we build one, we still need to answer a more useful question: which kind of table, and what should that particular table contain?

This is the story of how definitions give that answer in a simple, consistent shape.
